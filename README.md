# VidGrab

Расширение для Chrome и Яндекс Браузера. Качает видео (с выбором качества) или звук (оригинал или MP3 320/192/128) с YouTube и ещё ~1800 сайтов, которые поддерживает [yt-dlp](https://github.com/yt-dlp/yt-dlp).

Только Windows 10/11 x64.

## Установка

**Одной командой** (PowerShell):

```powershell
irm https://raw.githubusercontent.com/Chifer123536/vidgrab/main/get.ps1 | iex
```

**Или вручную:** Code → Download ZIP → распаковать → запустить `install.cmd`.

Установщик:
- скачивает `yt-dlp` (nightly), `deno` (нужен yt-dlp для YouTube) и `ffmpeg` в `%LOCALAPPDATA%\VidGrab\bin`;
- собирает помощник `vidgrab-host.exe` компилятором .NET Framework, который есть в любой Windows;
- регистрирует помощник для Chrome, Яндекс Браузера и Edge (`HKCU\...\NativeMessagingHosts`);
- копирует расширение в `%LOCALAPPDATA%\VidGrab\extension` и кладёт этот путь в буфер обмена.

Потом один раз в браузере:
1. Открыть `chrome://extensions` (в Яндексе `browser://extensions`).
2. Включить «Режим разработчика».
3. «Загрузить распакованное» → вставить путь `%LOCALAPPDATA%\VidGrab\extension`.

Без магазина расширений не обойтись: Chrome Web Store не пропускает загрузчики YouTube.

## Пользоваться

- Значок на панели → «Видео» или «Звук» → качество → «Скачать».
- Правый клик по странице или ссылке → VidGrab → «Скачать видео» / «Скачать звук». Используется последнее выбранное качество.
- Файлы сохраняются в «Загрузки». Папку меняет кнопка «Изменить» внизу попапа.

## Обновление

- yt-dlp обновляется сам раз в сутки. Если загрузка падает, он обновляется сразу и пробует ещё раз.
- Новая версия расширения: повторить установку (команда или `install.cmd`). Браузер подхватит её сам.

## Если не качает

| Симптом | Что делать |
|---|---|
| «Помощник не установлен» | Запустить `install.cmd`. |
| YouTube качает со скоростью 20–50 КБ/с | Это замедление YouTube в РФ. yt-dlp ходит в сеть напрямую, мимо VPN-расширения браузера. Нужен системный VPN или обход DPI, либо локальный прокси VPN-клиента в настройках (⚙ → «Прокси», например `socks5://127.0.0.1:10808`). |
| Возрастное ограничение / «докажите, что вы не бот» | Войти в аккаунт на сайте в этом же браузере и повторить. Куки сайта подставляются, только если без них не получилось. |
| Сайт открывается только через VPN-расширение | Указать прокси в настройках. |

## Удаление

`uninstall.cmd`, затем удалить VidGrab на странице расширений.

## Как устроено

```
popup / меню ─► background.js ─(native messaging)─► vidgrab-host.exe ─► yt-dlp.exe ─► ffmpeg, deno
```

- `extension/`: MV3-расширение. Попап, фоновый service worker, иконки.
- `host/VidGrabHost.cs`: native messaging хост. Запускает yt-dlp, разбирает прогресс, отменяет загрузки через Job Object (вместе с дочерними ffmpeg и deno), показывает окно выбора папки.
- `install.ps1` / `uninstall.ps1`: установка и удаление, всё в пределах текущего пользователя (без прав администратора).
